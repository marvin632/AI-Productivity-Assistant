# AI-Productivity-Assistant

An AI-powered workplace productivity assistant that helps users generate professional emails, summarise meetings, plan tasks, and receive workplace assistance.

Designed to save time, reduce manual work, and help users stay organised and productive at work.

---

## Project Overview

The AI-Productivity-Assistant is a smart assistant built to help professionals and students handle everyday workplace tasks faster and more efficiently.

Many people spend a lot of time writing emails, organising tasks, and summarising long meetings. This project uses AI to automate those tasks so users can focus on more important work.

The assistant can:
- Write clear and professional emails
- Summarise long meetings into short, useful notes
- Create daily task plans and to-do lists
- Answer workplace-related questions
- Help with writing, planning, and organising

**Target Users:** Office workers, students, job seekers, managers, and remote workers.
**Goal:** To improve productivity, save time, and make workplace communication easier.

---

## Features Implemented

- **Email Generator:** Generate professional emails for work, job applications, apologies, follow-ups, and requests.
- **Meeting Summariser:** Summarise long meeting notes into key points, decisions, and action items.
- **Task Planner:** Create daily and weekly task plans and prioritised to-do lists.
- **Workplace Assistant:** Ask workplace questions and get clear, helpful answers.
- **Task Prioritisation:** Organise tasks by urgency and importance.
- **Simple and Clean Interface:** Easy to use for anyone, even without technical skills.
- **Copy and Save:** Copy generated content to use in emails, documents, or notes.
